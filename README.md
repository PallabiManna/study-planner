📚 Study Planner

A simple and responsive study task management web application.

✨ Features
• Add Study Tasks
• Edit Tasks
• Delete Tasks
• Mark Tasks as Completed
• Priority Management
• Search Tasks
• Filter Tasks
• Sort Tasks
• Today's Tasks
• Overdue & Upcoming Tasks
• Local Storage
• Task Notifications
• Responsive Design

🛠️ Technologies Used
• HTML
• CSS
• JavaScript

💻 How to Run
1. Download or clone this repository.
2. Open index.html in a web browser.
3. Start adding your study tasks.
